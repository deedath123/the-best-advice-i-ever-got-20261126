## Entry

> When I was sixteen, my grandfather handed me his dented toolbox at 5 AM and said, "Son, nobody remembers how fast you started — they remember whether you showed up when it broke."

## How it works

`main.py` (Python 3.13, standard library only) writes the single-sentence entry to `/output/entry.txt`.

Run it with:

```sh
python3 -P -s main.py
```
